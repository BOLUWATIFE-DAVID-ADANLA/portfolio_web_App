## The problem

Payment-like APIs fail in specific, well-known ways: duplicate requests, partial failures, retries that double-charge. This is a personal project built to demonstrate the reliability patterns that matter most in that space — not a claim about any employer's system.

## The plan

Once built, the write-up will cover idempotency key design, handling retries and partial failures safely, and the observability needed to actually trust a payment-adjacent service in production.
