## The problem

Agents are only as useful as the tools they can safely call. This project exposes a set of internal APIs through an MCP server, with the access boundaries and validation an AI agent needs so it can act on real data without becoming a liability.

## The plan

Once built, the write-up will cover tool design (what an agent should and shouldn't be able to call directly), auth and scoping, and the failure modes that matter most when an LLM is the one holding the keys.
