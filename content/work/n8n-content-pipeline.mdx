## The problem

n8n gets treated as a toy for simple triggers. This project uses it as a real integration layer: pulling raw content from a source, running it through an LLM step for structuring and summarizing, and publishing the result — without a fragile pile of custom glue code.

## The plan

Once built, the write-up will cover why n8n was the right layer for orchestration versus writing custom services, how the LLM step is prompted and validated, and what breaks first when a pipeline like this runs unattended.
